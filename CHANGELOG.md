# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-08-19

### Added

- Authenticated real-page browsing through Rammerhead/TestCafe Hammerhead.
- Trusted HTTPS LAN mode with an installable local root certificate.
- Loopback-only VPS mode for Caddy or Nginx HTTPS termination.
- Persistent browser sessions, secure auth cookies, diagnostics, and private
  destination blocking.
- Windows and Linux instructions, systemd/Caddy templates, automated tests,
  dependency auditing, and GitHub CI.
